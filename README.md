# AI QA Copilot Frontend

React + TypeScript frontend for **AI QA Copilot**, an AI-powered Quality Engineering Platform.

## Current Product Scope

- AI test case generation, Playwright skeletons, and test history.
- Project, requirement, review, manual execution, analytics, billing, workspace, and AI provider modules.
- Repository Intelligence navigation for application repositories, automation repositories, repository activity, AI impact analysis, Playwright update workflow, validation history, and release readiness.
- GitHub Actions validation visibility with AI failure analysis, AI auto-fix proposals, retry validation, and release readiness dashboard.

## Development

```bash
npm install
npm run dev
npm run build
```
